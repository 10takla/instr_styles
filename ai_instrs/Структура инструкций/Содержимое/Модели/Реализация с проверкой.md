Модель реализации с проверкой отделяет контекст этапа от реализации и проверки результата.

**Обязательные структурные части:**
- `Implementation Instructions` содержит адресованные агенту действия, необходимые для получения результата этапа.
- `Verification`

**Формат:**
```md
<[](<../_.md#предисловие>)>

<###> Implementation Instructions

<[](<../Разделы/_.md>)>

<###> Verification

[Действия, подтверждающие, что результат этапа соответствует цели или ожидаемому состоянию, заданным в содержимом этапа. Проверяется результат этапа, а не факт выполнения агентом Implementation Instructions.]
```
