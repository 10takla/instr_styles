Сформируй черновики на основе [](<../Структура инструкций/_.md>).

## Неявные

Для каждого неявного `meta.yaml`:
```yaml
conditions:
  - implicit_invocation
```

- `style-context` — [](<../Структура инструкций/_.md>) и общие определения [](<../Структура инструкций/Содержимое/_.md>)
- `stages` — [](<../Структура инструкций/Этапы.md>)
- `content-sections` — [](<../Структура инструкций/Содержимое/Типы.md>) и [](<../Структура инструкций/Содержимое/Разделы/>)

Для `stages` и `content-sections` `content.md` в начале:
```md
**Связанные правила:**
- @draft(style-context)
```

## Явные

Для каждого явного `meta.yaml`:
```yaml
conditions:
  - explicit_invocation
```

Для каждого явного в `content.md` в начале:
```md
**Связанные правила:**
- @draft(style-context)
- @draft(stages)
- @draft(content-sections)
```
