Раздел обозначается так:
```md
**`<sectionName>`:** `<sectionContent>`
```

### Вход

**Формат:**
```md
**Входные данные:** `<InputList>`
```
, где `InputList` = [](./Типы.md#list), где `var` = `<название аргумента> — <описание аргумента>`

### Выход

**Формат:**
```md
**Выходные данные:** `<List>`
```


### Вход/выход

**Входные данные:**
- `otherSections` — другие разделы

**Формат:**
```md
<[](#вход)>

`<otherSections>`

<[](#выход)>
```
, где `InputList` = [](./Типы.md#list), где `var` = `<название аргумента> — <описание аргумента>`


### Инструкции

### Другие разделы
 
**Название:** "Выходные данные"
**Тип содержимого:** [](./Типы.md#list)
**Описание:** Любые входные данные, которые необходимы для решения задачи, дополнительная информация. Служит для определения поведения агента для старта реализации инструкций.]

**Название:** "Задача"
**Тип содержимого:** [](./Типы.md#descr)
**Описание:** Конкретные действия

**Название:** "Алгоритм"
**Тип содержимого:** [](./Типы.md#list)
**Описание:** Иногда хватает только задачи.

**Название:** "Требования"
**Тип содержимого:** [](./Типы.md#list)
**Описание:** Требования к выполняемым действиям

**Название:** "Формат вывода"
**Тип содержимого:** [](./Типы.md#list)
**Описание:** В каком виде мы ожидаем ответ от агента.

**Название:** "Выходные данные"
**Тип содержимого:** [](./Типы.md#puncts)
**Описание:** Отличие от **Формата вывода**: здесь мы ожидаем конкретный результат. Куда его записать/сохранить, допустим, и т.д.
