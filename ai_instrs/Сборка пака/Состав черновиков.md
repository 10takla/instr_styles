Сформируй черновики на основе [](<../Структура инструкций/_.md>).

## Неявные

Для каждого неявного `meta.yaml`:
```yaml
conditions:
  - implicit_invocation
```

### `style-context`

Сформируй общий контекст интерпретации стилей из [](<../Структура инструкций/_.md>), [](<../Структура инструкций/Нотация.md>) и общих определений [](<../Структура инструкций/Содержимое/_.md>).

Включи в него правила применения стилей, интерпретацию форматов и нотации, а также общие понятия содержимого, его элементов и опциональности. Не включай подробные правила этапов, разделов и отдельных моделей содержимого.

### `stages`

Сформируй правила этапов и подэтапов из [](<../Структура инструкций/Этапы.md>).

`content.md` в начале:
```md
**Связанные правила:**
- @draft(style-context)
```

### `content-sections`

Сформируй правила типов, разделов и их композиций из [](<../Структура инструкций/Содержимое/Типы.md>), [](<../Структура инструкций/Содержимое/Разделы/_.md>) и [](<../Структура инструкций/Содержимое/Разделы/Композиции.md>).

`content.md` в начале:
```md
**Связанные правила:**
- @draft(style-context)
```

## Явные

Сформируй каждый файл из [](<../Структура инструкций/Содержимое/Модели/>) как отдельный черновик с явным вызовом. Не объединяй модели в один черновик.

Для каждого:
- `meta.yaml`:
  ```yaml
  conditions:
    - explicit_invocation
  ```
- `content.md`:
  ```md
  **Связанные правила:**
  - @draft(style-context)
  - @draft(stages)
  - @draft(content-sections)
  ```
