## Типы содержимого

**Входные данные:**

- `var` — содержимое одного элемента.

### `Text`

**Формат:**

```md
`<var>`
```

### `List`

**Формат:**

```md
- `<var>`
...
```

Используй только маркированный ненумерованный список.

### `TextOrList`

Используй один текстовый блок `Text` или маркированный список `List`.

## Разделы

Формируй раздел из названия и содержимого. Определяй назначение и допустимый тип содержимого по виду раздела.

**Форматы:**

```md
**<sectionName>:** <Text>
```

или

```md
**<sectionName>:**
<List>
```

Формируй содержимое разделов по указанным типам.

### Виды разделов

- **«Входные данные»** — `List`, где каждый элемент имеет формат `` `<название входного элемента>` — <описание входного элемента> ``. Перечисляй значения, файлы, ссылки и дополнительный контекст, доступные агенту до выполнения задачи и необходимые для её исполнения.
- **«Задача»** — `Text`. Кратко описывай требуемое действие или преобразование.
- **«Инструкции»** — `TextOrList`. Описывай последовательность адресованных агенту действий для выполнения задачи в текущем контексте. Располагай действия в порядке зависимостей: каждое последующее действие предполагает выполнение необходимых предыдущих действий или наличие требуемого ими состояния.
- **«Алгоритм»** — `List`. Описывай независимую от конкретного исполнителя последовательность логических операций, преобразующую входное состояние в результат. Располагай элементы в порядке выполнения операций.
- **«Требования»** — `List`. Перечисляй обязательные свойства выполняемых действий или их результата.
- **«Формат вывода»** — `TextOrList`. Задавай структуру и способ представления ответа агента.
- **«Результат»** — `TextOrList`. Описывай ожидаемое состояние после выполнения задачи или этапа.
- **«Выходные данные»** — `List`. Перечисляй конкретные значения, файлы или артефакты, которые нужно создать, передать или сохранить, включая место сохранения.

## Композиция «Вход/выход»

**Входные данные:**

- `otherSections` — другие разделы.

**Формат:**

```md
<Раздел "Входные данные">

`<otherSections>`

<Раздел "Выходные данные">
```

Примеры:

- Для композиции с инструкциями передай в `otherSections` раздел «Инструкции».
- Для композиции с алгоритмом передай в `otherSections` раздел «Алгоритм».
